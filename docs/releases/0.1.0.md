# ReadingGlass 0.1.0 preview

Native macOS screen translation using local Vision, MLX TranslateGemma and Core ML background refinement.

## Included

- Click-through reading glass with display-relative startup size and bounded automatic widening.
- Coordinated dragging, independent sizing and menu-bar controls.
- Large-area OCR that bounds Vision input and preserves stable text when background pixels animate.
- Conservative label/numeric handling, safe text layout, progress and retry states.
- Cut-off or potentially incomplete edge text stays original, including when no more width is available.
- Source-sized text, matched ink color and aligned placement, with paragraphs kept close to their original UI area.
- Copy Screenshot: capture the current area behind the glass to the PNG clipboard without saving a file.

## Install

Download the `macOS-arm64.zip` asset and extract `ReadingGlass.app`. Requires Apple silicon and macOS 15 or later. Grant Screen Recording permission and use the app to install its approximately 2.22 GB translation model.

This is an **early, not-notarized preview**. GitHub-built packages use ad-hoc signing; macOS may prevent them from opening. Building locally from the tagged source is an alternative. Do not disable system-wide security protections to run the preview.

## Known limits

- Translation quality and complex screen layouts still need broader validation.
- Background refinement approximates the original UI; it does not reconstruct arbitrary interfaces perfectly or in real time.
- Animated text itself is retained as original content until stable.
- Physical multi-display dragging and long-session behavior are not fully validated.
- Capturing to the clipboard is explicit; the image remains there until it is replaced. Pasting into another service is your choice.

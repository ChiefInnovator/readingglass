# Contributing

ReadingGlass is an early preview under [PolyForm Strict 1.0.0](LICENSE). The license restricts modification and distribution. Open an issue describing a reproducible problem or proposed change; obtain the author's permission before preparing contributions that require additional rights.

- Keep changes focused and preserve the local-only processing model.
- Use synthetic text and images in tests. Never attach private screen captures, recognized text, credentials or model weights.
- Run `./scripts/build.sh` and `./scripts/test.sh` for app changes.
- Run `python3 scripts/check-site.py` for website changes.
- Record what was tested and distinguish automated checks from live desktop acceptance.

Third-party model/library licenses remain separate.

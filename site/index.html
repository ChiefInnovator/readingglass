A reading tool, right on your screen.

ReadingGlass is a native macOS utility that translates screen text inside a movable, click-through reading glass. Recognition, translation and background refinement run on your Mac.

↔

Place it over the words.

Drag the toolbar to position the glass. Adjust its size, or let it widen when text needs more room. It stays on one display.

Aa

Read in place.

Choose a target language. Translated paragraphs appear inside the glass, with an original-view control and a full-text view when needed.

⌘

Keep using your Mac.

The glass passes clicks and scrolling through to the app beneath it. A menu-bar control keeps pause, show/hide and reset close by.

Your text stays here.

Build it. Try it.

ReadingGlass is currently a source-build preview. A notarized installer and Mac App Store release are not currently provided.

Get build instructions
  1. Prepare your Mac

    Apple silicon, macOS 15 or later, Xcode, and uv for the one-time background-model preparation.

  2. Build the app

    Clone the repository and run ./scripts/build.sh. The build guide explains the dependencies.

  3. Give it a view

    Grant Screen Recording permission and install the local translation model. The model download is approximately 2.22 GB.

A few clear answers.

What is ReadingGlass?

ReadingGlass is a native macOS utility that translates screen text inside a movable, click-through reading glass. Recognition, translation and background refinement run on your Mac.

Is my screen text sent to a cloud AI service?

No. Screen recognition, translation and background refinement run locally. Model files are downloaded separately; captured images and recognized text are not uploaded by the app.

Does ReadingGlass work offline?

Translation runs locally after the required model files are installed. Initial model downloads and development-tool installation require an internet connection.

What does ReadingGlass require?

An Apple silicon Mac running macOS 15 or later, Screen Recording permission, and the local translation model. Building from source also requires Xcode and uv for the one-time background-model preparation.

How do I get ReadingGlass?

ReadingGlass is currently a source-build preview. Get the source and build instructions from its GitHub repository. A notarized installer and Mac App Store release are not currently provided.

Which languages can I use?

Choose from the target languages available in the app’s local model. Quality varies by language, screen layout and source text. Not every language pair has been validated.
